# Fin-Mod-1
Fintech Model (Version 1, Simple)

The financial model addressed here mimics the approach taken to model NFL point spreads. The definitive version of that neural net model consistently achieved 60% verified accuracy. The R&D focus was directed more on the actual competition between teams A and B and less on modeling each team individually. The financial model developed here considers two equities (A and B) that are anticorrelated. In so doing, the model under development needs to represent competition between these two equities in a way to predict the future winner and loser. The NFL point spread model needed to be more than 52.5% accurate to be successful in terms of making money. The financial model only needs to be more than 50% accurate to achieve measured success. 

With the accuracy goals in view, it will be important to address market volatility and its effect on any structured, machine-learning model. In other words, the model needs to perform well and not overact through turbulent times.
